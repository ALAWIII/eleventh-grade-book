# أنواع المؤسسات وقطاعاتها

## تصنيف المؤسسات

تُعرَّف المؤسسات من خلال قطاعاتها المختلفة، ويمكن تصنيفها حسب **نوع الملكية** أو **نوع المنتج/الخدمة** التي تقدمها.

### 1. حسب نوع الملكية

| النوع                         | الوصف                                      | أمثلة                                             |
| ----------------------------- | ------------------------------------------ | ------------------------------------------------- |
| **الخاص**                     | مؤسسات تهدف للربح ويمتلكها أفراد أو شركات. | مصمم ديكور، حضانة، سائق أجرة، ورشة ميكانيكا.      |
| **العام (الحكومي)**           | دوائر حكومية تقدم خدمات للمواطنين.         | وزارة الدفاع، قسم التعليم.                        |
| **الخيري / غير الهادف للربح** | مؤسسات تهدف لدعم قضايا إنسانية أو بيئية.   | منظمة أكسفام، الصندوق العالمي للطبيعة، اليونيسف.  |
| **التطوعي**                   | تعتمد على العمل التطوعي لخدمة المجتمع.     | خدمة التطوع الدولية.                              |
| **الشركات (مساهمة/تضامنية)**  | كيانات تجارية كبيرة أو شراكات مهنية.       | بنوك، شركات طيران، عيادات طب أسنان، مكاتب محاسبة. |

### 2. حسب نوع المنتج أو الخدمة

- **تصنيع المنتجات:** مثل مصنع سامسونج للإلكترونيات.
- **بيع المنتجات:** مثل متجر وولمارت أو أمازون.
- **توفير الخدمات:** مثل صالون تصفيف الشعر، تنظيف المنازل، أو جليسة أطفال.
- **المنتجات والخدمات معاً:** مثل شركات الطيران التي تنقل الركاب (خدمة) وتبيع الوجبات (منتج).
