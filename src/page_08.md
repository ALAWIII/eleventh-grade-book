# أنظمة جمع البيانات وإدخالها وأنظمة التنقل والاتصالات

### أولاً: أنظمة تسجيل وجمع البيانات

> **تعريف:** تعمل أنظمة تسجيل وجمع البيانات، المعروفة أيضاً باسم **(EDC) نظام التسجيل الإلكتروني للبيانات**، على التقاط المعلومات وجمعها بغرض أداء مهمة محددة.

**أمثلة على أنظمة جمع البيانات:**

| النظام                                 | الاستخدام                                                             |
| -------------------------------------- | --------------------------------------------------------------------- |
| الماسحات الضوئية للباركود              | إدخال البيانات بسرعة (عمليات الدفع، خدمات البريد السريع)              |
| تحديد الهوية عبر ترددات الراديو (RFID) | تتبع علامات الأمان في السلع ببيع التجزئة                              |
| أجهزة الاستشعار في السيارات            | المساعدة في عملية وقوف السيارات                                       |
| محطات الطقس                            | أجهزة استشعار لقياس أنماط الطقس ودرجة الحرارة والضغط والرطوبة والرياح |
| آلات المسح الطبي                       | MRI، CT، DEXA                                                         |
| أنظمة EDC في التجارب السريرية          | جمع البيانات بغرض تحليلها                                             |

### ثانياً: أنظمة التنقل 🗺️

> **تعريف:** هي تلك التي تستخدم نظام تحديد المواقع العالمي **(GPS)** أو النظام العالمي للملاحة عبر الأقمار الصناعية **(GLONASS)** للانتقال إلى المواقع.

**المعلومات التي يمكن أن تقدمها:**

- الازدحام المروري
- أعمال الطرق
- الحوادث
- الطقس
- نقاط الاهتمام

**أنواع أنظمة التنقل:**

- يمكن أن تكون منتجات تنقل مستقلة (مثل منتجات Garmin أو Tom-Tom)
- يمكن تركيبها في المركبات لتمكين السائق من التنقل
- بعض الدراجات النارية تأتي مزودة بنظام (GPS)
- قد يكون لديك نظام ملاحة مدمج في هاتفك الذكي يتيح لك العثور على طريقك أثناء القيادة أو ركوب الدراجات أو المشي

### ثالثاً: أجهزة وأنظمة الاتصالات 📡

> 📌 تُعد الاتصالات ضرورية في أنظمة المعلومات اليوم. تسمح أجهزة وأنظمة الاتصالات للأجهزة الرقمية بالتواصل مع بعضها البعض سواء في نفس الغرفة أو على الجانب الآخر من العالم.

**أنواع الاتصالات:**

| النوع                          | الوصف                                                                                                                                 |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| **الأقمار الصناعية**           | تعمل باستخدام طبقات الأقمار الصناعية كطريقة ثنائية الاتجاه لنقل البيانات (خيار مخصص للمناطق النائية التي لا يتوفر فيها النطاق العريض) |
| **Wi-Fi (IEEE 802.11)**        | يقوم بتوصيل الأجهزة دون أسلاك باستخدام موجات راديو عالية التردد                                                                       |
| **الألياف إلى الخزانة (FTTC)** | يوفر النطاق العريض للألياف الضوئية بشكل أسرع من الكابلات النحاسية                                                                     |
| **الألياف إلى المبنى (FTTP)**  | يوفر النطاق العريض بشكل أسرع من FTTC                                                                                                  |
| **4G/LTE/5G**                  | شبكات بيانات محمولة عالية السرعة توفر الاتصال أثناء التنقل (سرعات تصل إلى 50 Mbps)                                                    |
| **البلوتوث**                   | يُستخدم غالباً لشبكات المنطقة الشخصية (PANs) لتوصيل الأجهزة الطرفية                                                                   |

### المصطلحات الرئيسة

| المصطلح       | التعريف                                                                        |
| ------------- | ------------------------------------------------------------------------------ |
| النطاق العريض | تقنية إرسال عالية السرعة تُستَخدم من خلالها نطاق واسع من الترددات لنقل الرسائل |
| IEEE 802.11   | يشير إلى مجموعة من القواعد أو البروتوكولات المتعلقة بالشبكة المحلية (LAN)      |
| Mbps          | مقياس سرعة ميغابت في الثانية (Megabits per Second)                             |

---

### 💡 اقتراحات للتحسين

- **إضافة خريطة تفاعلية** توضح كيف يعمل GPS مع الأقمار الصناعية.
- **إضافة مخطط مقارن** لسرعات الاتصال (FTTC vs FTTP vs 5G).
- **إضافة رسم توضيحي** يشرح الفرق بين الشبكات السلكية واللاسلكية.
- **إضافة نشاط بحثي:** "ابحث عن كيفية بدء الثورة الرقمية وإنشاء الويب العالمية."
- **ربط:** الإشارة إلى صفحة 16 لمزيد عن البلوتوث.
