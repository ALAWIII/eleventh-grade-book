# مقدمة الوحدة

# الوحدة الأولى (أ): أنظمة تكنولوجيا المعلومات

## نظرة عامة

تؤثر تكنولوجيا المعلومات في حياتنا اليومية بشكل متزايد، وتعتمد على أجهزة الحاسوب لأداء أبسط المهام مثل معرفة الوقت. تهدف هذه الوحدة إلى:

- **اكتشاف** كيف تلبّي البنية الأساسية لتكنولوجيا المعلومات احتياجات المؤسسات وأصحاب المصلحة.
- **فهم** كيفية استفادة المؤسسات من البيانات والمعلومات.
- **وضع** سياسات استخدام تكنولوجيا المعلومات داخل المؤسسة.

## المهارات المستهدفة

| المهارة                | الوصف                                                 |
| ---------------------- | ----------------------------------------------------- |
| التحليل واتخاذ القرار  | تحليل المشكلات التقنية واتخاذ قرارات مبنية على معطيات |
| التواصل الكتابي الرسمي | صياغة تقارير ومراسلات مهنية واضحة                     |

## المصطلحات الرئيسة

| المصطلح                 | التعريف                                                    |
| ----------------------- | ---------------------------------------------------------- |
| البنية الأساسية         | المرافق والخدمات التي تحتاجها المؤسسة لمزاولة أعمالها      |
| أصحاب المصلحة           | أشخاص لديهم اهتمام مالي أو بعمل المؤسسة (داخليون وخارجيون) |
| الإجراءات               | خطوات منظمة تُتَّبع لضمان ثبات وتوحيد العمل                |
| السياسات                | قواعد يجب على الأفراد والمؤسسات الالتزام بها               |
| النفقات العامة          | التكاليف التي تتكبدها المؤسسات للمباني والمعدات والتوظيف   |
| الاستعانة بمصادر خارجية | تنفيذ إحدى الوظائف من قِبل متخصصين من الخارج               |
